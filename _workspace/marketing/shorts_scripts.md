# 유튜브 쇼츠 / 인스타 릴스 / 틱톡 스크립트

> 서비스: 내편계약서 (https://my-side-contract.vercel.app)
> 포맷: 세로 9:16, 30~45초. 세 플랫폼 동일 소스 활용.
> 원칙: 첫 3초 훅이 생명. "변호사 대체" 금지, "AI 분석 도구·참고용" 명시. 자막은 화면 가독성 우선 짧게.

## 스크립트 A — "이 조항 사인하지 마세요" (정보형, 약 35초)

**컨셉:** 위험 조항 3개를 빠르게 보여주는 정보 전달형. 저장·공유 유도.

| 시간 | 화면 지시 | 내레이션 | 자막 (화면 텍스트) |
|------|-----------|----------|---------------------|
| 0~3초 | 계약서 위에 빨간 펜이 멈춰 있는 클로즈업 | "이 조항 있는 계약서, 절대 사인하지 마세요." | 이 조항 있으면 ❌ 사인 금지 |
| 3~12초 | 계약서 문구 확대 + 빨간 밑줄 | "첫째, '입주 당시 상태로 원상복구'. 이거 있으면 벽지 누래진 것까지 다 내 돈으로 물어줘야 해요." | ① "입주 당시 상태로 원상복구" → 자연 마모도 내 책임 |
| 12~21초 | 다른 문구 확대 + 빨간 밑줄 | "둘째, '옵션 고장 시 임차인이 수리비 부담'. 노후로 인한 고장은 원래 집주인 책임인데도요." | ② "옵션 고장 임차인 부담" → 노후 고장은 집주인 책임 |
| 21~30초 | 또 다른 문구 확대 + 빨간 밑줄 | "셋째, '전입신고 하지 않는 조건'. 이건 보증금 보호를 못 받아요. 전세사기 1순위 신호입니다." | ③ "전입신고 금지" → 전세사기 위험 신호 |
| 30~35초 | 휴대폰으로 계약서 촬영하는 손 + 서비스 화면 | "사인 전에 계약서 사진 한 장이면, AI가 위험 조항을 짚어줘요. 참고용으로 꼭 확인하세요." | 사인 전 1분 점검 · 내편계약서 |

**자막 마지막 프레임:** `계약서 AI 분석 · 3,900원 · my-side-contract.vercel.app`

## 스크립트 B — "보증금 떼인 썰" (스토리텔링형, 약 40초)

**컨셉:** 실패담 1인칭 스토리. 댓글 "나도 당했다" 유도 → 알고리즘 부스터.

| 시간 | 화면 지시 | 내레이션 | 자막 (화면 텍스트) |
|------|-----------|----------|---------------------|
| 0~3초 | 통장 잔액 또는 정산 문자 화면 클로즈업 | "저, 이거 모르고 사인했다가 80만 원 날렸어요." | 보증금 80만 원 날린 썰 |
| 3~13초 | 자취방 입주 장면 (밝은 톤) | "첫 자취였어요. 부동산 사장님이 '다 똑같은 양식이에요' 하길래 그냥 사인했죠." | "다 똑같은 양식이에요" ← 이 말 위험 |
| 13~25초 | 이사 나오는 장면 + 정산서 클로즈업 (어두운 톤) | "이사 나올 때 도배비, 청소비로 80만 원 떼였어요. 계약서에 '원상복구' 조항이 있었던 거예요. 원래 자연 마모는 집주인 책임인데." | 자연 마모 = 집주인 책임 (그런데 떼임) |
| 25~35초 | 휴대폰으로 계약서 분석하는 화면 | "그때 알았으면 막을 수 있었어요. 요즘은 계약서 사진 올리면 AI가 불리한 조항을 법령이랑 대조해서 알려주더라고요." | AI가 법령 대조해서 위험 조항 확인 |
| 35~40초 | 차분한 마무리 컷 | "여러분은 사인 전에 꼭 한 번 확인하세요. 참고용이지만, 안 보는 것보단 훨씬 나아요." | 사인 전 1분 = 보증금 수백만 원 |

**자막 마지막 프레임:** `내편계약서 · 커피값으로 사는 안심 · my-side-contract.vercel.app`

## 스크립트 C — "AI한테 계약서 보여줬더니" (시연·반응형, 약 30초)

**컨셉:** 서비스 시연. 호기심 자극 + 결과 충격. 직접 노출형.

| 시간 | 화면 지시 | 내레이션 | 자막 (화면 텍스트) |
|------|-----------|----------|---------------------|
| 0~3초 | 계약서를 휴대폰 카메라로 비추는 손 | "계약서를 AI한테 보여줬더니, 이런 게 나왔어요." | 내 계약서를 AI한테 보여줬더니… |
| 3~12초 | 업로드 → 로딩 화면 | "작년에 사인했던 제 원룸 계약서를 사진 찍어서 올려봤어요. 1분쯤 기다리니까 결과가 떴는데…" | 사진 올리고 1분 대기 |
| 12~22초 | 분석 결과 화면 (불리한 조항 리스트 강조) | "불리한 조항이 4개나 나왔어요. 게다가 '주택임대차보호법 몇 조' 이렇게 실제 법 조문까지 짚어주더라고요." | 불리한 조항 4개 + 법령 조항 번호 제시 |
| 22~30초 | 사용자 표정 또는 결과 스크롤 | "변호사 대체는 아니고 참고용이지만, 사인 전에 이 정도만 알아도 진짜 든든해요." | 참고용 AI 분석 · 사인 전 필수 점검 |

**자막 마지막 프레임:** `내편계약서 · 출시 특가 3,900원 · my-side-contract.vercel.app`

## 공통 제작 가이드

- **훅 우선:** 0~3초 안에 손실(80만 원 날림)·금지(사인하지 마세요)·호기심(이런 게 나왔어요)을 던진다.
- **자막 필수:** 무음 시청자가 다수. 모든 내레이션은 짧은 자막으로 동시 노출.
- **속도감:** 컷 전환 2~4초 간격. 정적인 화면 지양.
- **금지 표현:** "변호사 대체", "100% 정확", "완벽 분석" 사용 금지. "참고용", "AI 분석 도구" 명시.
- **CTA:** 마지막 프레임에 서비스명·가격·URL 고정 노출. 영상 설명란에도 링크 1회.
- **플랫폼별 미세 조정:**
  - 유튜브 쇼츠: 제목에 키워드("원룸 계약서", "전세사기") 포함.
  - 인스타 릴스: 첫 댓글에 링크, 캡션에 해시태그(#자취 #전월세 #계약서 #자취준비).
  - 틱톡: 트렌드 사운드 활용 가능, 자막 더 크고 굵게.
- **재생산:** 업로드 48시간 후 반응 좋은 컨셉을 변형(다른 계약서 종류 — 알바/프리랜서 버전)해 시리즈화.
