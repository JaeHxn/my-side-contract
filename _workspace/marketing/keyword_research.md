## 1. 핵심 키워드 트렌드 요약

### 트렌드 지수 기준 해석
네이버 DataLab의 검색량 비율(ratio)은 조사 기간 내 최고값을 100으로 정규화한 상대 지수입니다.

### 검색량 규모별 키워드 분류

| 키워드 그룹 | 평균 지수 | 규모 | 특징 |
|------------|---------|------|------|
| 근로계약서 / 표준근로계약서 | ~82 | 초대형 | 연간 꾸준한 고볼륨, 최고 94.6(2025-07) |
| 전월세 계약서 / 임대차 계약서 | ~63 | 초대형 | 계절성 있음, 1월 피크(100), 이사철 급등 |
| 포괄임금제 / 포괄임금제 불법 | ~55 | 대형 | 변동성 높음, 4월 피크(100) |

| 계약서 독소조항 / 불공정 계약조항 | - | 미미 | DataLab 미집계 수준 |

## 2. 고가치 키워드 (기회 분석)

### 2-1. 즉시 공략 가능한 볼륨 대비 경쟁 낮은 키워드

#### "계약서 분석" / "계약서 검토"
- **검색량 지수:** 평균 0.39 (소형이지만 서비스 정확히 매칭)
- **검색 의도:** 거래성 (서비스를 찾는 고의도 사용자)
- **경쟁 강도:** 낮음
  - 웹검색 결과: 법무법인 고운, lawtalk.co.kr, 법률사무소 등 유료 변호사 서비스가 지배
  - AI 기반 서비스 전무 — **내편계약서의 블루오션**
- **전략:** 메인 랜딩 페이지 타이틀/메타에 1순위 삽입

#### "법률 AI" / "계약서 AI"
- **검색량 지수:** 2026년 들어 상승세 뚜렷 (2.3 → 4.5 → 5.1)
- **검색 의도:** 탐색성 + 정보성 (시장 자체가 성장 중)
- **경쟁 강도:** 중간
  - 웹검색 결과: 에버노트AI, lawform.io, 로톡AI 등 등장하나 임대차/근로 특화 서비스 부재
- **전략:** "계약서 AI 분석" 특화 콘텐츠로 차별화. 블로그 포스팅 소재로 활용

#### "전세 보증금 반환" / "전세보증금 보호"
- **검색량 지수:** 평균 2.6 (안정적)
- **검색 의도:** 정보성 + 거래성 혼재 (당장 문제가 생긴 사용자)
- **경쟁 강도:** 중간
  - 블로그 상위: 대형 법무법인 홍보글 다수, AI 서비스 없음
- **전략:** "계약서에서 보증금 보호 조항 확인하는 법" 콘텐츠로 내편계약서 연결

#### "계약갱신요구권"
- **검색량 지수:** 평균 3.5 (안정적, 법령 관심)
- **검색 의도:** 정보성 (권리를 이해하려는 사용자)
- **경쟁 강도:** 중간
  - 웹검색 상위: law.go.kr, easylaw.go.kr, molit.go.kr 등 공공기관 독점
  - 민간 서비스 부재 → 공략 가치 있음
- **전략:** "내 계약서에 계약갱신요구권 보호 조항이 있는지 확인하는 방법" 포스팅

## 3. 볼륨은 크지만 직접 경쟁 어려운 키워드 (우회 전략 필요)

### 3-1. 근로계약서 (지수 ~82, 초대형)
- **경쟁 강도:** 매우 높음
  - 고용노동부, 나무위키, easylaw.go.kr이 상위 3개 점령
  - 직접 공략 불가
- **우회 전략:**
  - **롱테일:** "근로계약서 불법 조항 확인법", "근로계약서 포괄임금제 조항 검토"
  - 블로그 상위 결과 분석: 노무사 개인 블로그들이 "독소조항", "불법조항" 등 실용 정보로 상위 노출 중 → 유사 콘텐츠 + 서비스 CTA 연결 가능

### 3-2. 전월세 계약서 / 임대차 계약서 (지수 ~63, 초대형)
- **검색 의도:** 혼재 (표준계약서 다운로드 / 작성법 / 주의사항)
- **경쟁 강도:** 높음
  - 법무부, easylaw.go.kr, welfarehello.com 등 공공/정보 사이트
  - 블로그: "전월세 계약서 주의사항" 총 10,390개, 상위는 개인 부동산 블로그
- **우회 전략:**
  - "전월세 계약서 작성 후 AI로 독소조항 확인하는 법" 각도로 차별화
  - 계절성 활용: 1월(이사철) 전 11~12월에 집중 포스팅

### 3-3. 포괄임금제 / 포괄임금제 불법 (지수 ~55, 대형)
- **경쟁 강도:** 중~높음
  - 고용노동부 신고센터, 노동법 정보 사이트(nodong.kr), 뉴스 기사
- **우회 전략:**
  - "내 근로계약서에 포괄임금제 조항이 불법인지 확인하는 법" 콘텐츠
  - 4월~6월(연초 취업 시즌) 피크에 맞춰 캠페인 게시

### 3-4. 전세사기 / 깡통전세 (지수 ~75, 대형)
- **검색 의도:** 정보성 + 공포성 (사기 예방 정보 탐색)
- **경쟁 강도:** 높음
  - HUG, KAMCO, 경기도 등 공공기관 및 뉴스 도배
- **우회 전략:**
  - "전세사기 예방 체크리스트 — 계약서 서명 전 꼭 확인할 5가지 조항"
  - 내편계약서 서비스와 직접 연결하는 실용 가이드

## 5. 콘텐츠 갭 분석 (아직 없는 콘텐츠)

네이버 검색 결과 분석 결과, 아래 콘텐츠는 **공급이 희박하거나 전무**합니다.

### 갭 1: "AI + 계약서 + 일반인" 교차 콘텐츠
- 현재 AI 계약서 검색 결과: 기업 법무팀 대상(B2B), 개발자 대상 기술 블로그 위주
- **없는 것:** 일반인(세입자, 알바생, 취준생)을 위한 AI 계약서 분석 실용 가이드
- **기회:** "근로계약서 받았는데 AI로 분석해봤더니..." 형식의 체험기

### 갭 2: "계약서 독소조항" + "법령 근거" 결합 콘텐츠
- DataLab에서 "계약서 독소조항" 검색량 미미 → 이 키워드 자체를 몰라서 못 검색
- 그러나 "포괄임금제 불법"(지수 55)은 검색 — 문제는 알지만 계약서와 연결 못 함
- **기회:** "포괄임금제 불법인데 내 계약서에 있다면? → 즉시 분석"으로 연결

### 갭 3: 전세사기 예방 + 계약서 사전 분석 결합
- 전세사기 관련 콘텐츠: 사기 발생 후 대처 위주 (변호사 선임, 소송 등)
- **없는 것:** 계약 서명 전 사전 예방 목적의 계약서 분석 서비스 소개
- **기회:** "계약서 사인 전 5분 투자로 전세사기 예방하는 법"

### 갭 4: 실시간 법령 연동 분석 서비스
- 검색 결과에서 실시간 국가법령정보센터 API 연동 서비스: **전무**
- 경쟁사(웍스AI, ChatGPT 활용)는 법령 미연동 — 내편계약서의 핵심 차별점
- **기회:** "법령 데이터베이스와 실시간 대조하는 계약서 분석" 각도 강조

### 갭 5: "알바생 / 취준생" 타깃 계약서 콘텐츠
- 블로그 상위 결과: 부동산 투자자/공인중개사 타깃이 대다수
- **없는 것:** 생애 첫 취업/계약하는 2030세대를 위한 쉬운 계약서 가이드
- **기회:** "처음 받아본 근로계약서, 이렇게 읽으면 됩니다" 시리즈

## 6. 네이버 블로그 최적화 전략

### 6-1. 블로그 포스팅 우선순위 (ROI 기준)

1. **[즉시 작성]** "근로계약서 독소조항 8가지 완벽 정리" ← 이미 네이버 상위 블로그들이 검증한 수요
2. **[즉시 작성]** "전월세 계약서 작성 후 꼭 해야 할 3가지" (AI 분석 CTA 포함)
3. **[즉시 작성]** "포괄임금제가 내 근로계약서에 있는지 5분 만에 확인하는 법"
4. **[1개월 내]** "전세 보증금 반환 거부, 계약서 어디를 봐야 하나"
5. **[1개월 내]** "계약갱신요구권, 내 계약서에 제대로 반영됐는지 확인하는 법"
6. **[이사철 전 집중]** "전세사기 예방 — 계약서 사인 전 체크리스트 10가지"

### 6-2. 포스팅 구조 템플릿 (네이버 블로그 SEO 최적화)

```
[제목 구조]
키워드 + 실용적 숫자 + 행동 유도
예: "근로계약서 불법 조항 8가지 — 사인 전 반드시 확인하세요"

[본문 구조]
1. 문제 공감 (사례, 통계)      ← 검색자의 고통점 직접 언급
2. 핵심 정보 (리스트/표)       ← 실제 법령 근거 포함 (내편계약서 강점)
3. 자가 체크 방법              ← 독자 행동 유도
4. 내편계약서 CTA              ← "AI로 바로 확인해보세요" + 링크
5. FAQ / 자주 묻는 질문        ← 롱테일 검색 추가 캡처

[필수 해시태그 예시]
#근로계약서 #계약서검토 #불법조항 #포괄임금제 #계약서AI #내편계약서
```

### 6-3. 계절별 콘텐츠 캘린더

| 시기 | 핵심 타깃 키워드 | 이유 |
|------|---------------|------|
| 1~2월 | 전월세 계약서, 임대차 계약서 | 이사철 피크 (지수 100 달성) |
| 3~4월 | 근로계약서, 포괄임금제 | 신학기·취업 시즌 (지수 급등) |
| 5~6월 | 계약갱신요구권, 전세 보증금 | 봄 이사철 후 분쟁 증가 |
| 7~8월 | 알바 계약서, 근로계약서 | 여름 알바 시즌 |
| 9~10월 | 전월세 계약서, 전세사기 예방 | 가을 이사철 |
| 11~12월 | 연말 계약 갱신, 임대차 갱신 | 연말 계약 정리 시즌 |
