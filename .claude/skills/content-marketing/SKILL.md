# 내편계약서 마케팅 콘텐츠 워크플로우

## Phase 0: 컨텍스트 확인

- 유형 미지정 → 사용자에게 확인 (블로그/커뮤니티/쇼츠 중 선택)
- 채널 미지정 → 유형에 따라 기본값 사용 (블로그: 네이버, 커뮤니티: 에브리타임)
- `_workspace/`에 이전 콘텐츠 있으면 톤/키워드 스타일 유지

## Phase 1: 콘텐츠 생성

`content-writer` 에이전트를 서브 에이전트로 호출한다.

```
Agent(
  subagent_type: "content-writer",
  model: "opus",
  prompt: "역할 파일: .claude/agents/content-writer.md\n\n{콘텐츠 유형}/{채널}/{주제 또는 키워드}"
)
```

## 콘텐츠 유형별 가이드

### 네이버 블로그 (SEO 최적화)

**구조:**
1. 제목: 타겟 키워드 포함 (30자 이내)
2. 도입부: 독자 상황 공감 (2~3문장)
3. 본문: 소제목 3~5개, 각 400자 이상
4. 결론: 행동 유도 + 서비스 링크 (자연스럽게)

**SEO 체크리스트:**
- [ ] 제목에 메인 키워드 포함
- [ ] 첫 단락에 키워드 반복
- [ ] 소제목에 롱테일 키워드 포함
- [ ] 이미지 alt 텍스트 작성 지침 포함
- [ ] 내부 링크 (서비스 페이지 연결) 1개 이상

**추천 키워드 조합:**
```
원룸 계약서 + [확인 방법 | 불리한 조항 | 주의사항]
전세 계약서 + [보증금 | 묵시적 갱신 | 특약]
알바 계약서 + [최저임금 | 불법 | 확인]
근로계약서 + [미작성 | 위반 | 필수 항목]
```

### 커뮤니티 포스팅

**에브리타임 (대학생 자취):**
- 200~400자, 말투: 반말/친근체
- "저 이번에 자취방 구하면서 계약서 보다가..." 형식 시작
- 직접 홍보 X, 경험 공유처럼

**블라인드 (직장인):**
- 300~500자, 말투: 존댓말
- 근로계약서, 퇴직합의서 주제
- "입사 때 이런 조항 사인했다가..." 형식

**네이버 카페 (자취생/부동산):**
- 500~800자, 정보성 글 형식
- 제목: "[정보] 이런 조항 있는 월세 계약서 주의하세요"

### 유튜브 쇼츠/틱톡 스크립트

**구조 (30~60초):**
```
[훅 0~3초] "이 조항 있는 계약서 절대 사인하지 마세요"
[문제 제시 3~15초] 실제 피해 상황 설명
[해결책 15~45초] 위험 조항 3가지 소개
[CTA 45~60초] "AI로 미리 확인하세요" + 서비스 링크
```

## 이사 시즌 우선순위

| 월 | 주력 주제 |
|----|---------|
| 1~3월 | 주거 계약서 (신학기, 이사 성수기) |
| 4~5월 | 근로계약서 (신입 입사 시즌) |
| 6~7월 | 주거 계약서 (여름 이사) |
| 8~9월 | 근로계약서, 알바 계약서 (신학기 알바) |
| 10~12월 | 웨딩 계약서 (예약 시즌) |

## 산출물

- 완성 콘텐츠 텍스트 직접 출력
- `_workspace/content_{YYYYMMDD}_{유형}.md` 저장 (재사용/수정 대비)
