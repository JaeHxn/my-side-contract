# 선착순 10명 무료 이벤트 운영 방식

기존에 사전 발급했던 무료 코드는 모두 폐기 처리했습니다. 이 이벤트는 코드를 미리 나눠주는 방식이 아니라, 사용자가 신청한 뒤 관리자가 선착순으로 승인하는 방식으로 운영합니다.

## 사용자 흐름

1. 사용자가 `https://my-side-contract.vercel.app` 접속
2. `3,900원으로 분석하기` 클릭
3. 결제 페이지에서 이름과 이메일 입력
4. 실제 입금은 하지 않고 `결제 신청하기` 제출
5. 선착순 10명에 해당하면 관리자가 승인
6. 시스템이 6자리 분석 코드를 이메일로 발송
7. 사용자는 `/upload`에서 계약서와 코드를 입력해 1회 분석

## 관리자 흐름

1. `/admin` 접속
2. `결제 요청 목록`에서 `pending` 신청을 접수순으로 확인
3. 선착순 10명은 입금 확인 없이 `승인 + 이메일` 처리
4. 11번째 이후 신청은 일반 결제 안내 또는 이벤트 마감 안내

## 인스타 안내 문구 핵심

“이름과 이메일만 입력해 신청하세요. 선착순 10명은 입금 없이 무료 승인해드립니다.”
