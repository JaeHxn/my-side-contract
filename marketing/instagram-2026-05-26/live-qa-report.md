# 내편계약서 라이브 QA 리포트

대상: https://my-side-contract.vercel.app  
일시: 2026-05-26 KST  
방법: 병렬 QA 에이전트 4명 + 로컬 Playwright 스모크 테스트. 실제 개인정보는 사용하지 않고 합성 계약서/더미 파일만 사용했습니다.

## 종합 결과

| 영역 | 결과 | 심각도 | 핵심 증거 | 권장 조치 |
|---|---|---:|---|---|
| 홈/첫 화면 | 통과 | 낮음 | 서비스 목적, 가격, CTA가 데스크톱/모바일에서 명확함 | 유지 |
| 업로드/TXT/MD | 통과 | 낮음 | TXT/MD 파일 업로드 즉시 textarea 반영, OCR 호출 없음 | 유지 |
| PDF/이미지 OCR | 통과 | 낮음 | 합성 PNG/PDF OCR 200, 추출 텍스트 반영 | 유지 |
| 분석 코드 오류 | 통과 | 낮음 | 가짜 코드 제출 시 `/api/analysis` 401, “입력한 코드가 확인되지 않습니다.” 표시 | 유지 |
| 실제 성공 결과 | 미검증 | 중간 | 유효 운영 코드를 소진하지 않는 QA fixture가 없음 | 스테이징/QA 전용 코드 또는 fixture 결과 URL 마련 |
| 긴 텍스트 처리 | 개선 필요 | 중간 | 60,000자 TXT가 50,000자로 잘리지만 경고 없음 | “일부 내용 제외” 경고 표시 |
| 잘못된 파일 후 상태 | 개선 필요 | 중간 | 유효 파일 후 비지원 파일 선택 시 이전 본문/파일명 유지 | “기존 내용 유지 중” 안내 또는 기존 내용 초기화 |
| 개인정보 신뢰 문구 | 개선 필요 | 중간 | `/privacy`에는 안내가 있으나 `/upload` 입력부 근처에는 보관/OpenAI 전송 안내가 부족 | 입력폼 근처에 짧은 개인정보 안내와 링크 추가 |
| 모바일 터치 타깃 | 개선 필요 | 중간 | 일부 링크/버튼 높이 44px 미만 | 모바일 interactive 요소 `min-height: 44px` 적용 |
| 키보드 포커스 | 개선 필요 | 중간 | 파일 input 포커스가 1x1 sr-only에 감, textarea/input focus 표시 약함 | `focus-visible`, `focus-within` 링 보강 |
| 결제 폼 라벨 | 개선 필요 | 중간 | 입금자명/이메일 input의 명시적 label 연결 부족 | `id`/`htmlFor`, `autocomplete` 추가 |
| CSP/폰트 | 개선 필요 | 중간 | Pretendard CDN CSS가 CSP에 차단됨 | 폰트 self-host 또는 CSP 허용 도메인 정리 |

## 우선순위

1. QA 전용 성공 코드/fixture를 만들어 실제 결과 카드까지 회귀 테스트.
2. `/upload` 개인정보 안내, 포커스 표시, 오류 접근성 개선.
3. 50,000자 초과 경고와 비지원 파일 선택 후 기존 내용 유지 안내 추가.
4. Pretendard 폰트 CSP 오류 정리.
